# Kineox guides

New to Kineox? Start with [Getting started](getting-started.md), then pick the experience you want to build.

| Guide | What you'll learn |
| --- | --- |
| [Getting started](getting-started.md) | Install Kineox and run your first video |
| [Player](player.md) | Controls, captions, keyboard shortcuts and borderless playback |
| [Showcase](showcase.md) | Product demos, ambient video, previews and expansion |
| [Customization](customization.md) | Themes, CSS variables and custom controls |
| [Recipes](recipes.md) | Common configurations you can copy and adapt |
| [Framework adapters](framework-adapters.md) | Integrate into React, Vue or another UI framework |
| [Compatibility](compatibility.md) | Browser behavior, accessibility and current limitations |
| [FAQ](faq.md) | Quick answers about media formats, autoplay and cleanup |

The full project includes a local playground. From the repository directory run `npm ci`, `npm run build`, and `npm run demo`, then visit http://localhost:8000/examples/.

The guides live on GitHub. They are deliberately left out of the npm tarball to keep the installation small.
